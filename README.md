# Surf City Training

Training tracker for the Surf City Marathon (Feb 7, 2027), installable on iPhone from Safari (Share → Add to Home Screen).

- `plan.json`: the schedule, paces and goals. Edit this to change the plan.
- `index.html`, `app.js`: the app. Progress is stored in the phone's browser storage, not in this repo.
- `sw.js`: offline support. Bump `CACHE` when changing app files.
